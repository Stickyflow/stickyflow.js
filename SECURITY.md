# Security

## Reporting a problem

If you find a security problem in stickyflow.js, report it privately, not in a public issue. Open the Security tab of this repository and
choose "Report a vulnerability". Only the maintainers see the report.

Say what is affected, how it can be reproduced and what could happen. You will get an answer within a few days, and the fix is published
together with a note on the problem once a release carries it.

## Versions

Fixes go into the latest release. While the version is below 1.0.0, older minor versions get no fixes of their own.
