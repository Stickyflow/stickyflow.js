SFL parser, scene builder, SVG renderer, interactive viewer and editing runtime in one package. No runtime dependencies, no React, no Konva. The static tier is DOM-free and runs in Node.

## Quick start

```ts
import { render } from 'stickyflow'

const { svg, width, height, diagnostics } = render(sfl)
// A complete, deterministic SVG string. render() never touches the DOM.
```

## Four entry points

| Import | What it is |
|---|---|
| `stickyflow` | Static tier. SFL text in, SVG string out. Node, SSR, CLI. |
| `stickyflow/viewer` | Read-only viewer in the DOM: select, hover, pan, zoom, typed events. |
| `stickyflow/interaction` | Editing gestures on a viewer. Reports what changed; the host applies the patch to the SFL text. |
| `stickyflow/web-component` | `<stickyflow-diagram>` custom element in Shadow DOM, no build step. |

Each tier only depends on the one below it; `test/boundary.test.ts` enforces that.

```ts
import { createViewer } from 'stickyflow/viewer'
import { bindEditing, applyMoveChange } from 'stickyflow/interaction'

const viewer = createViewer({ container, source: sfl, interactive: true })
const editing = bindEditing(viewer)

editing.on('moveChange', (event) => {
  sfl = applyMoveChange(sfl, event)   // the text changes, nothing else does
  viewer.update({ source: sfl })
})
```

## What it draws

Shapes, links, frames, swimlanes, paths and text. Fifteen chart types. Isometric objects. Shader surfaces and widgets. Data sources with bindings, and events with handlers, so a document can react to data and input.

## Principles

- **Deterministic.** The same SFL gives the same SVG, byte for byte.
- **Text stays the source.** Edits patch the SFL text; comments and order survive.
- **Layered.** Language, semantic, render input, scene, SVG, runtime, each with one job and one direction.

```
src/
  sflLanguage/   AST, lexer, parser, canonical emitter
  sflSemantic/   SFL AST to canvas state
  renderInput/   renderer contract and style decoding
  renderScene/   deterministic scene construction
  svg/           SVG serialization and the DOM contract
  runtime/       viewer, interaction, web component
```
