Execution Trace · ein konkretes Objekt

Eine abgerundete Box, Datei für Datei.

Diese Seite verfolgt genau einen Aufruf von render(source) für ein rounded_rectangle. Sie zeigt die aktive Funktionskette, die Verträge und die Module, die zwar geladen werden, deren Variantenpfad für dieses Beispiel aber nicht ausgeführt wird.

Die exakte Eingabe

import { render } from 'stickyflow';

const source = `sfl 1.2

Model Demo {
  Entity start {
    shape: rounded_rectangle
    text: "Start"
    layout {
      position: 40, 60
      size: 160, 80
    }
    style {
      fill: "#0f766e"
      stroke: "#5eead4"
      strokeWidth: 2
      cornerRadius: 14
    }
  }
}`;

const result = render(source);

Entscheidend ist shape: rounded_rectangle. kind: rounded_rectangle wäre keine Formauswahl: classifyEntity() liest die Form aus der Property shape, und shapeObject() würde andernfalls auf rectangle zurückfallen.

Geladen, aber hier nicht aktiv

Statische Imports machen weitere Module Teil des Bundles beziehungsweise Modulgraphen. Sie sind architektonisch beteiligt, ihre variantenspezifischen Funktionen laufen für dieses Shape aber nicht.
